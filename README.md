# Умывалочка 2.0

Статическое PWA без сервера. История ухода и дневник остаются в старых ключах `skin:*` в localStorage. Косметичка хранится в `skin:products`, фотографии — в IndexedDB `skin-photos`. Миграция версии 2 создаёт `skin2:safety:migration`, затем дополняет каталог из актуальных стандартных и пользовательских шагов. Повторный запуск не дублирует средства.

## Восстановление

В «Ещё → Резервная копия» можно скачать полный файл версии 2 (включая фото). Файлы версии 1 поддерживаются. Перед импортом показываются конфликты: слияние сохраняет локальное значение конфликтующего поля, полная замена требует подтверждения. Перед изменениями создаётся `skin2:safety:restore`.

После подключения Яндекс Диска существующая облачная копия не отправляется поверх нового пустого состояния. Откройте «Ещё → Яндекс Диск → Восстановить с Диска», просмотрите конфликты и выберите слияние или замену. Данные облака тестируются подставным API; проверка с реальным аккаунтом требует участия владельца. Экспорт в файл, Яндекс Диск и Telegram содержит фотографии; системные уведомления при закрытом браузере не предусмотрены.

## Проверки

```sh
npm ci
npm run lint
npm run test:unit
npm run build
npx playwright install chromium
npm run test:e2e
```

Локально при установленном системном Chromium: `CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e`.
